SISTEM PEMBELIAN TIKET BIOSKOP

Aplikasi console berbasis TypeScript untuk membantu petugas kasir atau admin loket bioskop mencatat, menghitung, mengubah, menghapus, dan mencari data pemesanan tiket.
Proyek ini dibuat untuk memenuhi Ujian Akhir Semester (UAS) mata kuliah Pemograman Dasar.

LATAR BELAKANG 

Pencatatan pembelian tiket secara manual (buku atau kertas) rawan salah hitung, data ganda, dan sulit dicari kembali.
Aplikasi ini membantu kasir mencatat pemesanan dengan cepat dan konsisten, menghitung total bayar secara otomatis, serta 
mengubah atau membatalkan pemesanan bila pembeli ganti keputusan.
